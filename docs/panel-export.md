# Physical panel export

CellStyle can export a Matplotlib figure or native ggplot to a declared physical
slot, then assemble checked SVG panels on one page at 100% physical scale.
These opt-in APIs leave existing theme defaults unchanged.

A figure layout describes the **whole artwork** and its panel rectangles in mm,
with origins measured from the top left. Slots must be finite, positive, inside
the page, unique and non-overlapping. Layouts are separate from identity/color
registries. The example below is synthetic, not a prescribed journal layout.

## Python

Install the optional PDF checker with `pip install 'cellstyle[export]'`.

```python
from pathlib import Path
import matplotlib.pyplot as plt
from cellstyle import FigureLayout, PanelSlot, export_panel, assemble_svg

layout = FigureLayout(
    'example', 183, 130,
    tuple(PanelSlot(key, x, y, 87, 60) for key, x, y in
          [('a', 3, 3), ('b', 93, 3), ('c', 3, 67), ('d', 93, 67)]),
    profile='nature-flagship-final-research',
)
layout.write('layout.json')
# Explicitly set every ordinary text role before rendering.
with plt.rc_context({'font.family': 'DejaVu Sans', 'font.size': 6,
                     'axes.labelsize': 6, 'axes.titlesize': 6,
                     'xtick.labelsize': 6, 'ytick.labelsize': 6}):
    fig, ax = plt.subplots()
    fig.subplots_adjust(left=.18, bottom=.22)
    ax.plot([0, 1, 2], [1, 3, 2])
    ax.set_xlabel('Synthetic x')
    ax.set_ylabel('Synthetic y')
# Save this example as a script; its hash links the export to plotting source.
export_panel(fig, layout, 'a', 'a.svg', source_path=__file__,
             font_family='DejaVu Sans')
export_panel(fig, layout, 'a', 'a.pdf', source_path=__file__,
             font_family='DejaVu Sans')
# After exporting each remaining slot from its own accepted plot:
# assemble_svg(layout, {key: Path(f'{key}.svg') for key in 'abcd'}, 'figure.svg')
```

The exporter resizes a copy of the figure canvas; it does not change font sizes,
data, axes limits or the source figure. Existing layout engines may reposition
artists on that copy. If text no longer fits, revise the plotting layout and
rerender. `bbox_inches` is rejected, and a global `savefig.bbox='tight'` is disabled
inside export. PDF fonts are embedded; SVG text remains editable and requires
the same installed font on the assembly machine. Matplotlib math/TeX text is
currently refused because its font roles need separate assessment.

`text_roles` maps artist `gid` strings to `ordinary` or `panel_letter`. Ordinary
is the default. Panel letters require `letter_owner='panel'`; the Nature profile
checks lowercase, upright bold 8 pt. With assembly-owned letters, add them once
in the assembly. An optional `letter_reserve_mm=(x,y,width,height)` on a slot
checks that Python text/legend bounds do not enter that area; marks still need
visual review.

## R

Install optional `jsonlite`, `digest`, `systemfonts`, `xml2`, and `svglite` packages.
PDF also needs Cairo support, Poppler `pdfinfo`, and Ghostscript `gs` on PATH.

```r
library(cellstyle)
library(ggplot2)
p <- ggplot(data.frame(x=1:3, y=c(1,3,2)), aes(x,y)) + geom_point() +
  theme_classic(base_size=6, base_family='Arial') +
  theme(axis.text=element_text(size=6), axis.title=element_text(size=6))
export_cellstyle_panel(p, 'layout.json', 'a', 'a.svg', 'plot.R', 'Arial')
export_cellstyle_panel(p, 'layout.json', 'a', 'a.pdf', 'plot.R', 'Arial')
```

R reads the same layout file and produces the same semantic layout hash. It
requires assembly-owned letters and currently refuses letter-reserve rectangles.
R checks declared font family, SVG text sizes, unrotated text bounds and actual
exported page dimensions. Rotated text and legend bounds remain review items.
Cairo rounds PDF device pages down to whole points; Ghostscript extends the
page box by less than 1 pt without scaling plot content. This can leave a small
extra edge margin compared with SVG. PDF font embedding remains a receipt review
item for R; Python's `measure_panel` can independently check the resulting PDF.
No Python process is used by the R exporter.

## Evidence and limits

Every asset gets an adjacent `.receipt.json` with source and asset SHA-256,
layout hash, panel ID, expected/measured size, and remaining review items.
Dimension tolerance is **0.02 mm**. Python reports `PANEL_GEOMETRY_TEXT_CHECKED`;
R reports `PANEL_GEOMETRY_CHECKED`. Neither status grants manuscript acceptance.
The source hash identifies the provided file; it cannot prove that the in-memory
plot was generated by that file or that data are scientifically accepted.

The optional Nature profile records the rules checked on **2026-09-28**:
89/183 mm whole-figure width, at most 170 mm height, ordinary text 5–7 pt,
and panel letters 8 pt. Sources: [research figure guide](https://research-figure-guide.nature.com/figures/building-and-exporting-figure-panels/)
and [final submission](https://www.nature.com/nature/for-authors/final-submission).
This is a dated, scoped rule snapshot, not a live publisher compliance guarantee.
It does not enforce all journal rules, including stroke widths. Recheck at submission.
Other Nature journals/stages need different profiles. **No Cell profile is shipped.**

Clipping inside axes, raster resolution, missing glyphs, typography after import,
readability and scientific meaning still require review. Existing 8 pt manuscript
themes do not automatically meet the Nature profile. No defaults are reduced
silently. Dense or unreadable panels must be deliberately rerendered for the slot.
