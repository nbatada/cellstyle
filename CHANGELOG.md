# Changelog

## 0.3.0 — 2026-10-17

- Add one-call default scatter and replicate plots in Python and R, with optional no-overwrite output.
- Add `style_plot` for supported native plots while retaining scientific encodings and Python multi-axes geometry.
- Include native R ggplot2 support, opt-in semantic text checks, and physical panel export/assembly.
- Keep pre-1.0 APIs provisional and scientific/visual acceptance with the user. See [release notes](docs/RELEASE_NOTES_v0.3.0.md).

## 0.2.0 — provisional source development

- Added a native ggplot2 package, additive themes and scales, replicate distributions, scatter, labels, and supplied statistical annotations.

## 0.1.2 — 2026-09-20

- Added public label repel and embedding helpers, with explicit display-label mappings.

## 0.1.1

- Added supplied-comparison rendering and installable Python packaging.

## 0.1.0 — 2026-09-19

- Initial Python visual grammar and plotting helpers.
